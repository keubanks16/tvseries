Show data key (one-time setup)

Show info, suggestions and streaming availability come from TMDB, which is free but needs your own key:

  1. Create a free account at themoviedb.org.
  2. Open Settings → API and request a key (choose “Personal” use).
  3. Copy the API Key and paste it here.
